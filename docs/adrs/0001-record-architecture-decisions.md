# 0001. Record architecture decisions

Date: 2026-07-29 · Status: accepted

Decisions live as ADRs in docs/adrs, one per decision, numbered, never
edited after acceptance (superseded by new ADRs instead). Requirements
(docs/adrs/requirements.md, R-numbers) say WHAT must be true; ADRs say WHY
we chose HOW. Any surface (chat, Claude Code, Copilot, Grok) may
propose an ADR; Andy accepts.
